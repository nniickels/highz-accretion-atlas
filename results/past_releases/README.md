# Past Results by Release

Each subdirectory is a frozen generated science or visualization release from
v1 through v7.4. Current v7.5 products are promoted to `results/figures/`,
`results/tables/`, and `results/galleries/`.

These directories are reproducibility snapshots, not competing current
answers. See [`../README.md`](../README.md) for the release-by-release inventory
and [`../../docs/publication/README.md`](../../docs/publication/README.md) for
the curated paper-ready subset.
