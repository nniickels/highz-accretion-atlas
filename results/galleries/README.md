# v7.5 growth gallery

The v7.5 catalogue has 219 physical objects. All 196 objects with canonical
numeric black-hole masses have unchanged growth inputs relative to v7.4, so
their 588 high-resolution object products and six zoomable compiled class grids
are inherited byte-for-byte from `results/past_releases/v7_4/galleries/`.

The current coverage table is
`results/tables/v7_5_growth_gallery_coverage.csv`. It records the
three inherited product paths for each eligible object and explicitly marks all
23 catalogue-only objects unavailable. This avoids duplicating roughly the
entire gallery while preserving exact, machine-verifiable current coverage.

The inherited grids compile all objects for each plot kind by class. They are
lossless/high resolution and intended to be zoomed rather than viewed as small
inline figures.
