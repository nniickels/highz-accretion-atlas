# Paper package

`highz_accretion_atlas_v7_5.tex` and its rendered PDF are the authoritative
v7.5 manuscript/status package. The earlier `.codex_tmp` status manuscript is a
historical development snapshot through the initial v7 catalogue layer and is
not current.

Compile from `paper/` with:

```bash
pdflatex -interaction=nonstopmode -halt-on-error highz_accretion_atlas_v7_5.tex
pdflatex -interaction=nonstopmode -halt-on-error highz_accretion_atlas_v7_5.tex
```
