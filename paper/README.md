# Paper package

`highz_accretion_atlas_v7_5.tex` and its rendered PDF are the authoritative
v7.5 manuscript/status package. The earlier `.codex_tmp` status manuscript and
roadmap/expansion documents are historical development records through earlier
project stages and are not current release guides. Current release instructions
live in `README.md`, `docs/getting-started.md`, and the v7.5 documentation.

Compile from `paper/` with:

```bash
pdflatex -interaction=nonstopmode -halt-on-error highz_accretion_atlas_v7_5.tex
pdflatex -interaction=nonstopmode -halt-on-error highz_accretion_atlas_v7_5.tex
```
