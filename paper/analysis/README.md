# Conservative manuscript analysis

Generated from canonical v3 tables and `paper/identity_exclusions.json` by
`src.internal.publication_selection`. Notebook 01 writes these products;
notebook 04 verifies their reproduction without rewriting.

- `publication_object_selection.csv`: all 338 provisional catalogue records,
  with explicit open-group, exclusion, primary and exploratory selection flags.
  Six records are excluded, including three mass-bearing records.
- `identity_exclusion_sensitivity.csv`: original and exclusion-sample counts,
  distribution summaries and top-five order for each of five scenarios. Reference
  p16 and P>=0.95 counts are included; blank entries for other scenarios mean
  not evaluated, not zero probability.

The 224/234 primary/exploratory samples exclude known open groups. This does not
assert exhaustive astrophysical uniqueness, demographic completeness, or resolved
identities. Original catalogue flags and all source measurements are unchanged.

Rebuild: `python -m src.internal.publication_selection --write`.
Check: `python -m src.internal.publication_selection`.
The stricter `python -m src.internal.verify_redshift_identity --require-resolved`
still fails on three groups and is not bypassed by this check.

Manuscript figures use the publication selection and are generated by
`src.internal.publication_figures` in notebook 02; notebook 04 checks regenerated
images with `--verify`. Original catalogue figures remain separate.

## Virial-mass scale sensitivity

`mass_offset_sensitivity.csv` summarizes the 224/234 publication samples at
fixed log-mass offsets of -0.5, -0.3, 0, +0.3 and +0.5 dex.
`mass_offset_object_sensitivity.csv` records the point requirement, p16 and
conditional P(>1) for each included object and offset, with measurement IDs,
error availability, random seeds and draw counts. Both are written and verified
by the same publication-selection commands above (notebooks 01 and 04).

The offsets translate the original 10,000 identifier-seeded reported-error draws;
no independent scatter is added, and missing-error objects retain unavailable
p16/probabilities. All reference growth parameters remain fixed. Zero offset
reproduces the canonical reported-error results. This coherent mass-scale stress
test does not infer calibration bias, model heterogeneous estimator correlations,
or marginalize over systematic uncertainty. The amplitude benchmark is motivated
by the approximately 0.5-dex single-epoch accuracy scale discussed in
[Shen (2013)](https://arxiv.org/abs/1302.2643), not a common JWST calibration prior.
