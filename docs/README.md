# Documentation

Start with the current dataset or the task-oriented guides. The retained
project record lives under [`archive/`](archive/README.md), so the top-level
documentation directory stays focused.

## Active documentation

- [`current/`](current/README.md): final v3 schema, workflows, and audits
- [`guides/`](guides/README.md): setup, reproduction, and dataset-versioning guidance
- [`reference/`](reference/README.md): stable project terminology and modeling conventions
- [`source-notes/`](source-notes/README.md): source extraction and admission records
- [`publication/`](publication/README.md): paper-ready figures, tables, supplements, and supporting documents

Authoritative source citations and limitations are consolidated in
[`../data/sources.md`](../data/sources.md) and the machine-readable
[`../data/source_provenance_registry.csv`](../data/source_provenance_registry.csv).

## Historical documentation

[`archive/`](archive/README.md) contains the append-only contribution ledger and
the current dated repository-status report. Obsolete release-era documentation,
schemas, and candidate lists were removed from the public tree and remain
recoverable from Git history; they do not define the current v1/v2/v3 dataset
contract.
