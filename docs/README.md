# Documentation Guide

Documentation remains at stable paths because release notes, tests, and frozen
manifests refer to those paths. This index groups the files by purpose without
duplicating or relocating authoritative documents.

Paper-ready figures, tables, supplements, and supporting documents are indexed
separately in [`publication/README.md`](publication/README.md).
