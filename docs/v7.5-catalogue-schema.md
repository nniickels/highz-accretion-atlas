# v7.5 catalogue schema

v7.5 extends frozen v7.4 with one provenance correction and recomputes the
physical-object evidence aggregate. It contains 234 measurements, 219 physical
objects, and 218 host systems.

The measurement schema is inherited unchanged. The object table adds:

- `all_measurement_evidence_statuses`
- `all_measurement_evidence_status_bases`
- `object_evidence_aggregation_policy`

Exactly one preferred measurement per physical object controls the object-level
`evidence_status` and `evidence_status_basis`. The history columns retain every
distinct measurement-level value. Eligibility is then recomputed from the
preferred status and existing numeric/method/identity/lensing contracts.

The Scholtz source has 21 admitted measurements at `z >= 4`, proven against
the complete 41-row source table. Its one identity-linked JADES 8083 row maps to
an existing broad-line object; the source therefore represents 21 physical IDs
within its measurement rows but contributes 20 narrow-line candidate objects to
the combined object-class counts. None has an inferred numeric black-hole mass.
