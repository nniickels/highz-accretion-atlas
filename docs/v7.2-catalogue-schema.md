# v7.2 catalogue-only GNIRS-50 extension

v7.2 non-destructively copies the frozen v7.1 catalogue and appends all 50
Shen et al. (2019) GNIRS source rows. It contains 211 measurements, 198
physical objects, and 197 host systems. Six GNIRS rows are reviewed alternate
measurements of XQR-30 objects.

The release adds no heterogeneous science ranking, uncertainty analysis, or
figure. Its 49 numeric GNIRS masses are eligible for the broad diagnostic tier;
the 29 Mg II fiducial measurements enter the primary luminous-quasar
comparison tier. J0055+0146 is retained without a numeric mass and excluded
from both tiers.

Canonical artifacts use the `v7_2_` prefix:

- measurement and physical-object catalogues;
- host systems and measurement/object/host links;
- aliases and six reviewed identity decisions;
- long-form source observables and catalogue strata.

The exact artifact membership, hashes, counts, source hashes, parent release,
and Python version are frozen in `releases/v7.2-catalogue-manifest.json`.
Reproduction is checked with:

```bash
python -m scripts.verify_v7_2_catalogue --reproduce
```

Earlier v7.0 and v7.1 files are immutable inputs, not rolling output names.
