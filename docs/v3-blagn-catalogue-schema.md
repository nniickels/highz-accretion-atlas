# v3 Expanded BLAGN Catalogue Schema

The v3 CEERS/RUBIES expansion is a separate release layer. It does not append to
`data/raw/v1_raw.csv`, overwrite `data/processed/v1_processed.csv`, or alter any
v1 result or ranking file.

## Release artifacts

- `data/raw/taylor24_ceers_rubies_blagn_table1.csv`: all 63 published Table 1
  measurements, including 26 rows below `z=4`.
- `data/crossmatch/v3_measurement_object_links.csv`: stable measurement-to-object
  links for v1 and Taylor, including the explicit CEERS/RUBIES duplicate.
- `data/processed/v3_blagn_measurements.csv`: 60 measurements at `z >= 4`
  (23 v1 plus 37 Taylor).
- `data/processed/v3_blagn_objects.csv`: 59 physical objects, represented
  by one documented preferred measurement each.

Regenerate only these two v3 processed files with:

```powershell
python -m scripts.process_v3_blagn
```

## Measurement and physical-object identity

`measurement_id` identifies one source-paper measurement and remains unique.
`object_id` preserves the source-paper name. `physical_object_id` identifies the
astrophysical source across measurements. Crossmatch decisions and preferred
measurement choices live in the separate link table, with a method, reference,
and reason, rather than being encoded by deleting rows.

Taylor identifies `CEERS-2782` and `RUBIES-EGS-50052` as the same object. Both
measurements are retained under `HZA-CEERS-2782`. The RUBIES spectrum is the
preferred object-view measurement because the paper adopts its higher-S/N
measurement and describes severe spatial slit loss in CEERS-2782.

`v3_blagn_measurements.csv` is the lossless analysis view.
`v3_blagn_objects.csv` is the deterministic deduplicated view. It adds
`n_measurements`, `available_measurement_ids`, and `available_object_ids` so the
selection remains auditable.

## Taylor source fields

The source-specific raw table preserves the canonical identifiers, coordinates,
spectroscopic redshift, and virial mass fields plus:

| Field group | Columns |
| --- | --- |
| Survey context | `program`, `field`, `selection_channel`, `broad_line_species` |
| Halpha observables | total, narrow, and broad fluxes with asymmetric errors, all in `1e-18 erg s-1 cm-2` |
| Broad-line width | `halpha_broad_fwhm_km_s` and asymmetric errors; `fwhm_instrument_corrected_flag` |
| Phenotype and fit | `lrd_flag`, `lrd_definition`, `halpha_absorption_fit_flag` |
| Mass uncertainty | `log_mbh_systematic_dex`, `mbh_systematic_kind`, `mbh_systematic_applied_flag`, `mbh_formal_uncertainty_kind` |
| Source state | dust-correction flag, caveat tags, paper version, URLs/DOI, archive hash, extraction date, selection criteria |

`lrd_flag` is an independent observational phenotype. It does not replace
`object_class`; every Taylor row remains `broad-line-agn` under the paper's
selection.

The mass method is
`single-epoch-virial-halpha-reines2013`, identifying the Reines et al. (2013)
Halpha single-epoch calibration. The tabulated asymmetric mass errors are formal
posterior errors. The paper's approximate `0.5 dex` virial-calibration scatter
is recorded separately and is not added to those errors. Nominal Table 1 fluxes
and masses are not dust corrected.

## Missing-value policy

Taylor Table 1 does not publish host stellar masses, bolometric luminosities, or
Eddington ratios. Their raw and standardized fields remain blank. The pipeline
does not derive them to satisfy the v1 schema, and dependent quantities such as
`log_mbh_mstar_ratio` and `edd_ratio_from_mbh_lbol` remain unevaluable.

## Reproducibility and rankings

The existing v1/v2 scripts continue to read only frozen v1 inputs; therefore
v1 baseline products and v2 rankings, figures, results, and numeric regression
anchors are unchanged.
No v3 ranking or science figure is generated by the catalogue-processing script;
those are separate reproducible workflow steps.

The v3 rankings state whether they use the measurement view or the
preferred physical-object view. They keep formal posterior sampling separate
from the Taylor virial systematic, apply that systematic as explicit `+/-0.5
dex` sensitivity scenarios, and mark missing Mstar/Lbol/Eddington-ratio
diagnostics unavailable without a ranking penalty. Ranking outputs record the
input release and preferred-measurement policy. See
`docs/v3-blagn-science-workflow.md`.

See `docs/taylor24-ceers-rubies-extraction-notes.md` for source verification and
unresolved source limitations.
