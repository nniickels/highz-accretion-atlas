# Current documentation

The current scientific endpoint is dataset v3. The v1, v2, and v3 definitions
are in [`../guides/versioning.md`](../guides/versioning.md). The remaining files
in this directory describe the final heterogeneous v3 schema, science policy,
atlas, claim audit, citation audit, and the dated
[`literature-scope policy`](literature-scope.md).

v1 and v2 use the same analysis contract and figure definitions at smaller
catalogue scope.
