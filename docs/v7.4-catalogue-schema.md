# v7.4 JADES narrow-line/high-ionization catalogue

v7.4 copies frozen v7.3 and adds 20 Scholtz et al. candidates at `z >= 4`.
It contains 233 measurements, 218 physical objects, and 217 host systems.
One new measurement is a second evidence view of existing JADES 8083, leaving
19 new objects. The 209/196 growth-eligible measurement/object populations and
the 182 primary measurement population are unchanged because the new source
publishes no numeric black-hole masses. The conservative all-measurements
object evidence rule changes the primary-object count from 171 to 170: the
added candidate classification for JADES 8083 coexists with its secure
preferred broad-line mass measurement, so its object evidence is `candidate`.

The release includes 87 new long-form observables: stellar mass, SFR, MUV, and
bolometric luminosity for all 20 rows, plus seven detected Ne IV, Ne V, or N V
line fluxes. It records one reviewed manual identity assertion and preserves
the paper's 42-claimed versus 41-tabulated discrepancy.
