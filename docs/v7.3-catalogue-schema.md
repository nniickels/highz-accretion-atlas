# v7.3 UHZ1 X-ray Evidence-History Catalogue

v7.3 copies frozen v7.2 and adds two literature assessments of one resolved
UHZ1 physical object. It contains 213 measurements, 199 physical objects, and
198 host systems. The 209/196 growth-eligible measurement/object populations
and 182/171 primary populations are unchanged because neither UHZ1 row has a
defensible canonical numeric black-hole mass.

Build and verify with:

```bash
python -m scripts.process_v7_3_catalogue
python -m scripts.verify_v7_3_catalogue --reproduce
```

The release writes measurement, preferred-object, host-system, identity-link,
alias, observable, and strata tables under the `v7_3_` prefix. Its identity
candidate table is empty but schema-preserving: both measurement versions are
explicitly assigned to the same source-verified UHZ1 object before batch
assembly, and neither matches a prior atlas object.

The preferred object row is the 2026 reanalysis and aggregates the worst
evidence status, `disputed`. The original candidate row remains available in
the measurement table. Twenty-two new observables preserve the original X-ray
claim, the assumption-dependent mass bounds, reanalysis significance range,
bolometric upper limit, both lensing versions, and all nine MIRI upper limits.

The frozen `v7.2-class-aware-science` tables continue to evaluate the frozen
v7.2 catalogue. v7.3 does not silently regenerate or relabel them, and it adds
no figures.
