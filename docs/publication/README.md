Claim audits, citation audits, release manifests, tests, and verification
scripts support the paper but are not themselves intended as manuscript pages.
They remain public so every released claim and artifact can be audited.

The CSV tables are scientifically released and supplement-ready, but they are
not journal-formatted LaTeX tables. The only formatted table currently embedded
in the manuscript is the release-scale summary defined directly in the TeX
source.
