# Figure supplement and galleries

[`results/v3/gallery/per_object/`](../../../results/v3/gallery/per_object/)
contains one parameter map, one growth track, and one seed-redshift map for all
219 catalogue objects.
The 196 supported objects receive numerical products; the other 23 receive
explicit no-inference status panels. Catalogue-wide parameter, compatibility,
and Monte Carlo atlases are in `results/v3/figures/`.

The coverage boundary is machine-checked by `src.internal.verify_versions`.
