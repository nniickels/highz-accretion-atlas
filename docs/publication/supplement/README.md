# Figure Supplement and Galleries

The complete growth supplement covers all 196 eligible v7.5 objects with three
products each: a parameter-map sheet, seed-redshift map, and reference growth
track. Because the eligible inputs are unchanged from v7.4, the 588 images and
six compiled class grids remain at their frozen v7.4 paths.
