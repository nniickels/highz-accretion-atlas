# Figure supplement and parameter maps

[`results/v3/parameter_maps/`](../../../results/v3/parameter_maps/) contains two axis-named
folders: `fedd_mass_maps/` and `seedredshift_mass_maps/`, with one panel of
each kind for all 219 catalogue objects.
The 196 supported objects receive numerical products; the other 23 receive
explicit no-inference status panels. Catalogue-wide $f_{Edd}$-mass,
growth-track, and Monte Carlo atlases are in `results/v3/figures/`.

The coverage boundary is machine-checked by `src.internal.verify_versions`.
