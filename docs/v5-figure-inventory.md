# v5 Figure Inventory

The v5 paper-facing set is generated by:

```powershell
python -m scripts.generate_v5_final_figures
```

It reads only the canonical v5 result tables and writes new files under
`results/past_releases/v5/figures/main_text/`. Frozen v1--v4 figures are not overwritten.

The canonical PNG membership and SHA-256 hashes are recorded separately in
`releases/v5-figures-manifest.json`. Verify them without rewriting any figure:

```powershell
python -m scripts.verify_v5_figures
```

The figure manifest is separate from the CSV manifest because exact rendered
bytes can depend on platform graphics and font libraries. The pinned project
environment is used to generate the canonical files; the cross-platform v5 CSV
reproduction gate remains independent of rendering.

## Appendix figure

| Figure | Role |
| --- | --- |
| `v5_appendix_measurement_choice_sensitivity.png` | One-at-a-time substitution of all seven nondefault literature measurements. |

The duty fraction is a deterministic rescaling of the required lifetime-average
rate for fixed burst and quiescent rates. It therefore does not define an
independent rank; the primary growth-pressure ordering remains canonical.

The v4 figures remain the frozen previous-release record. They may be cited for
release-to-release comparison, but they no longer represent the current sample
and should not be used for unqualified v5 claims.

All curves and ranks are assumption-conditioned observational-triage products.
They are not fitted accretion histories, demographic estimates, or proof of a
seed channel.
