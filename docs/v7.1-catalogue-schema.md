# v7.1 catalogue-only XQR-30 extension

v7.1 non-destructively copies the frozen v7.0 catalogue and appends the 42
E-XQR-30 luminous quasars as a distinct comparison stratum. It does not rewrite
the v7.0 files and does not generate rankings, demographic inference, or
figures.

## Cardinalities

- 161 literature measurements
- 154 physical objects
- 153 host systems
- 42 XQR-30 measurements, all in `luminous_quasar_comparison`
- 364 source-local observables, including 294 from XQR-30
- 203 alias rows
- zero coordinate/redshift candidates against v7.0
- 23 explicitly reviewed external-literature repeats

The XQR-30 canonical row uses the published MgII mass with its statistical
errors and a separate 0.55 dex scaling-relation systematic. CIV quantities are
alternate observables. WISEA J0439+1634 remains explicitly lensed and
uncorrected. Four published MgII Eddington-ratio inconsistencies are retained
with machine-readable flags and independently computed comparison values.

## Products and reproduction

All new outputs use a `v7_1_` prefix. The exact product set and hashes are in
`releases/v7.1-catalogue-manifest.json`.

```bash
python -m scripts.process_v7_1_catalogue
python -m scripts.verify_v7_1_catalogue --reproduce
```

See `docs/xqr30-extraction-notes.md` for source archives, aliases, caveats, and
identity decisions. Any later source family must use another release prefix;
v7.0 and v7.1 are immutable inputs, not rolling output filenames.
