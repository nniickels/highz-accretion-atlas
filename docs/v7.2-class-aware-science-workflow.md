# v7.2 Class-Aware Science Workflow

## Scope

This analysis release evaluates the frozen `v7.2-accreting-atlas-catalogue`.
It does not alter catalogue rows, preferred measurements, evidence labels, or
source values. The analysis includes the 209 eligible measurement rows and 196
eligible preferred physical-object rows. The massless GNIRS row and the
uncorrected lensed XQR row remain in the catalogue and are recorded in a
separate four-row exclusion audit at both entity levels.

The heterogeneous catalogue is not a demographic sample. Global orderings are
navigation aids only. The primary interpretive ranks are calculated within
object class and mass-comparability group; primary-tier ranks add the evidence
filter already encoded by the catalogue. The checked-in policy table explicitly
forbids pooled demographic inference without a selection function and
completeness model.

## Reproduction

Run from the repository root in the pinned Python 3.12 environment:

```bash
python -m scripts.generate_v7_2_class_aware_science --n-samples 10000 --seed 20260808
python -m scripts.verify_v7_2_science --reproduce
```

The verifier checks exact manifest membership and SHA-256 hashes, rebuilds all
eight tables in memory, and does not write an artifact. CI adds
`--require-clean` to prove that verification does not mutate the checkout.

## Products

- `v7_2_class_aware_measurement_point_ranking.csv`: 209 eligible literature
  measurements with global-navigation, class, mass-group, joint-stratum, and
  primary joint-stratum ranks.
- `v7_2_class_aware_object_point_ranking.csv`: the equivalent 196-row preferred
  physical-object view.
- `v7_2_class_aware_measurement_uncertainty_ranking.csv` and
  `v7_2_class_aware_object_uncertainty_ranking.csv`: split-normal Monte Carlo
  propagation of published statistical black-hole-mass errors.
- `v7_2_class_aware_class_method_summary.csv`: 36 descriptive strata; every row
  is marked as unsuitable for demographic inference.
- `v7_2_class_aware_exclusion_audit.csv`: retained catalogue rows excluded from
  growth ranking, with explicit reasons.
- `v7_2_class_aware_alternate_measurement_sensitivity.csv`: all 13 eligible
  nonpreferred measurements compared with their frozen preferred object row.
- `v7_2_class_aware_science_policy.csv`: machine-readable interpretation rules.

## Assumptions and uncertainty boundaries

The baseline uses `z_seed=30`, radiative efficiency `epsilon=0.1`, and
`merger_boost=1`. Point tables report required lifetime-average Eddington ratios
for fixed seed masses and required seed masses for fixed accretion histories.
They do not equate a published instantaneous Eddington ratio with a lifetime
history.

Monte Carlo tables sample only published statistical mass errors using a
split-normal model in log mass. Source-provided systematic mass scales are
reported as separate point-estimate envelopes and are never folded into those
statistical draws. Rows with known source-internal Eddington-ratio
inconsistencies remain auditable but are excluded from current-versus-lifetime
ratio interpretation.

No figure release is part of v7.2 science. Figure design should follow only
after the class-aware tables and their comparison policy have been used to
select defensible panels.
