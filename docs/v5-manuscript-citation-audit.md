## Audit conclusions

- The bibliography metadata and the manuscript's source sample descriptions
  are consistent with the published primary records above.
- Taylor's published record supersedes the older 50-object preprint-era
  description. Current table anchors remain protected by an archived source
  checksum and regression tests; they must not be reconstructed from an
  abstract or secondary database.
- Claims about 106 measurements, 99 physical objects, 105/98 primary counts,
  exact ranks, LRD-state counts, overlaps, and duty-cycle summaries are results
  of this repository and should cite the relevant table or release, not imply
  that a source paper reported them.
- No pooled mixed-source demographic claim is supported by this audit.
